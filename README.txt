YANGILIK.UZ — News Website

Structure:
- index.html         Main page
- css/style.css      All styles
- js/main.js         Interactive functions
- images/            Local images can be placed here

How to run:
1. Open index.html in a browser.
2. For local development, use VS Code + Live Server.
3. Replace the demo image URLs in index.html with local files from images/ when needed.

Note:
The current demo uses remote Unsplash images, so internet access is required for those images.
